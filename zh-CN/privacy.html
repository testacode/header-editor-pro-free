隐私政策 - Header Editor Pro - Free

你的隐私很重要： 本扩展以隐私优先为原则设计。我们不收集、不存储、不传输任何个人数据。

数据收集

Header Editor Pro - Free 不会向外部服务器收集、存储或传输任何用户个人数据。扩展完全在你的浏览器内运行，不与任何远程服务通信。

本地存储

所有请求头配置、配置文件和设置，都通过浏览器的存储 API 保存在你的设备本地。这些数据包括：

  • 请求头修改规则和配置文件
  • 扩展的设置与偏好
  • 配置文件的名称及其配置

这些数据永远不会离开你的电脑，且只有扩展本身可以访问。你可以随时通过卸载扩展或清除浏览器数据来删除它们。

权限

本扩展需要以下权限才能运行：

  • declarativeNetRequest: 用于拦截并修改 HTTP 请求头
  • storage: 用于将你的配置保存在本地
  • tabGroups: 用于读取 Chrome 标签组的名称和颜色，从而把配置文件限定到该标签组
  • 访问所有网站 (<all_urls>)： 请求头规则由浏览器自身通过 declarativeNetRequest 应用。扩展不会读取页面内容，也从不查看它所修改的请求。

这些权限仅用于扩展的功能实现，不用于收集数据。

第三方服务

本扩展不与任何第三方服务、分析平台或广告网络集成，也不向其发送数据。

本政策的更新

我们可能会不定期更新本隐私政策。任何变更都会体现在扩展中，以及下方的更新日期上。

联系方式

如果你对本隐私政策或扩展的数据处理方式有任何疑问，请通过 GitHub 上的支持渠道联系我们。
