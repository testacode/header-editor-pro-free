🎯 How It Works

🔧

1. Install & Open

Add the extension to Chrome and click the icon in your toolbar. You'll see a professional dark interface with profile circles on the left.

⚙️

2. Create Profiles

Click the "+" circle to create different header configurations. Each profile can have unlimited request and response headers.

🎯

3. Add Headers

Use the "Add header" buttons to create custom HTTP headers. Each header has a checkbox to enable/disable individually.

⚡

4. Instant Results

Headers are applied in real-time! Switch profiles by clicking numbered circles. Use the pause button to temporarily disable.

Modify request and response headers instantly using Chrome's latest declarativeNetRequest API. No page refreshes needed!

Toggle any header between set and append mode — perfect for multi-value headers like Accept, Cookie or Accept-Encoding.

Scope a profile to specific domains, or to a Chrome tab group — keep sandbox headers in their tabs and never mix environments again.
