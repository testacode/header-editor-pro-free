개인정보 처리방침 - Header Editor Pro - Free

당신의 개인정보는 소중합니다: 이 확장 프로그램은 개인정보 보호를 최우선으로 설계되었습니다. 어떤 개인 데이터도 수집, 저장, 전송하지 않습니다.

데이터 수집

Header Editor Pro - Free는 사용자의 개인 데이터를 외부 서버로 수집, 저장, 전송하지 않습니다. 확장 프로그램은 전적으로 브라우저 안에서 동작하며 어떤 원격 서비스와도 통신하지 않습니다.

로컬 저장소

모든 헤더 구성, 프로필, 설정은 브라우저의 저장소 API를 통해 사용자의 기기에 로컬로 저장됩니다. 저장되는 데이터는 다음과 같습니다:

  • 헤더 수정 규칙 및 프로필
  • 확장 프로그램의 설정 및 환경설정
  • 프로필 이름과 구성

이 데이터는 사용자의 컴퓨터를 벗어나지 않으며 확장 프로그램 자신만 접근할 수 있습니다. 확장 프로그램을 삭제하거나 브라우저 데이터를 지우면 언제든 삭제할 수 있습니다.

권한

이 확장 프로그램이 동작하려면 다음 권한이 필요합니다:

  • declarativeNetRequest: HTTP 헤더를 가로채고 수정하기 위해
  • storage: 설정을 로컬에 저장하기 위해
  • tabGroups: 크롬 탭 그룹의 이름과 색을 읽어, 프로필을 해당 그룹으로 한정할 수 있도록 하기 위해
  • 모든 웹사이트에 대한 접근 (<all_urls>): 헤더 규칙은 declarativeNetRequest를 통해 브라우저가 직접 적용합니다. 확장 프로그램은 페이지 내용을 읽지 않으며, 수정하는 요청을 들여다보지도 않습니다.

이 권한들은 오직 확장 프로그램의 기능을 위해서만 사용되며, 데이터 수집에는 사용되지 않습니다.
