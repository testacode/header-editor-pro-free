🎯 사용 방법

🔧

1. 설치하고 열기

크롬에 확장 프로그램을 추가하고 툴바의 아이콘을 클릭하세요. 왼쪽에 프로필 원이 배치된 세련된 다크 인터페이스가 열립니다.

⚙️

2. 프로필 만들기

"+" 원을 클릭해 용도별 헤더 구성을 만드세요. 프로필마다 요청·응답 헤더를 제한 없이 담을 수 있습니다.

🎯

3. 헤더 추가하기

"헤더 추가" 버튼으로 원하는 HTTP 헤더를 만드세요. 헤더마다 체크박스가 있어 개별로 켜고 끌 수 있습니다.

⚡

4. 즉시 적용

헤더가 실시간으로 적용됩니다! 번호가 매겨진 원을 클릭해 프로필을 전환하고, 일시정지 버튼으로 잠시 꺼둘 수도 있습니다.

💡 이런 상황에 딱 맞습니다:

🔐 API 테스트

Authorization: Bearer token123 을 추가해 인증이 필요한 엔드포인트를 테스트

🌐 CORS 디버깅

Access-Control-Allow-Origin: * 을 추가해 교차 출처 요청을 테스트

🧪 환경별 테스트

X-Environment: staging 을 설정해 다른 백엔드를 대상으로 테스트

🎭 User Agent 변경

User-Agent 를 바꿔 모바일과 데스크톱 응답을 비교

✨ 주요 기능

🆓 100% 영원히 무료

구독도, 프리미엄 등급도, 기능 제한도 없습니다. 월 5~15달러를 받는 경쟁 제품과 달리 모든 것이 완전히 무료입니다.

🎯 무제한 프로필

필요한 만큼 헤더 구성을 만드세요. 대부분의 무료 대안은 프로필을 3개로 제한합니다.

🌐 7개 언어

English, 简体中文, 繁體中文, 日本語, 한국어, Русский, Español — 툴바에서 바꾸거나 브라우저 언어를 따르도록 둘 수 있습니다.

⚡ 실시간 수정

크롬의 최신 declarativeNetRequest API로 요청·응답 헤더를 즉시 수정합니다. 페이지를 새로고침할 필요가 없습니다!

➕ 덮어쓰기 또는 덧붙이기

어떤 헤더든 덮어쓰기와 덧붙이기 모드를 오갈 수 있습니다. Accept, Cookie, Accept-Encoding처럼 값이 여러 개인 헤더에 안성맞춤입니다.

🗂️ 도메인·탭 그룹 필터

프로필을 특정 도메인이나 크롬 탭 그룹으로 한정하세요. 샌드박스 헤더를 해당 탭에만 묶어 두면 환경이 뒤섞일 일이 없습니다.

🎨 전문적인 인터페이스

번호가 매겨진 프로필 원, 헤더별 체크박스, 직관적인 조작을 갖춘 아름다운 다크 테마.

⏸️ 일시정지 기능

설정을 잃지 않고 모든 헤더를 잠시 꺼둘 수 있습니다. 결과를 빠르게 비교할 때 유용합니다.

💾 가져오기 및 내보내기

클릭 한 번으로 프로필을 JSON 파일로 백업하거나 공유하고, 설정을 가져올 수 있습니다. 다른 헤더 편집기에서 내보낸 프로필 목록도 지원합니다.

🔒 개인정보 우선

데이터 수집도 추적도 전혀 없습니다. 모든 설정은 사용자의 기기에만 저장됩니다.
