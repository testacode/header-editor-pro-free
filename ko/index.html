Chrome과 Firefox용 무료 오픈 소스 확장 프로그램입니다. 코드를 건드리지 않고 스테이징 테스트, 인증·CORS 디버깅, 환경 전환을 할 수 있습니다.

주요 기능

요청 헤더와 응답 헤더

어떤 헤더든 설정, 추가, 제거할 수 있습니다. 헤더마다 스위치와 메모가 있어 반년 뒤에도 그 토큰이 왜 있는지 알 수 있습니다.

환경 간 리디렉션

정규식과 일치하는 요청을 스테이징이나 로컬 서버 같은 다른 URL로 보냅니다. $1 캡처 그룹을 지원하며, 대상이 다른 출처라면 CORS를 켤 수 있습니다.

프로필별 쿠키

브라우저에 저장하지 않고 도메인 요청에 쿠키를 추가합니다. 일시 중지하거나 프로필을 바꾸는 즉시 멈추고, 사이트에 같은 이름의 쿠키가 있으면 경고가 표시됩니다.

그 밖의 기능

프로필과 필터

프로필은 필요한 만큼 만들 수 있고, 각각 특정 도메인이나 (Chrome에서는) 탭 그룹으로 제한할 수 있습니다.

가져오기와 내보내기

JSON 백업, 다른 헤더 편집기의 프로필 목록, Requestly 리디렉션 규칙.

활성 항목 공유

프로필에서 켜진 항목을 복사하면 동료가 바로 쓸 수 있는 프로필로 가져올 수 있습니다.

일시 중지

클릭 한 번으로 모든 규칙을 끕니다. 아무것도 잃지 않습니다.

설정 또는 추가

Accept나 Cookie 같은 다중 값 헤더는 교체하지 않고 값을 추가할 수 있습니다.

자주 쓰는 경우

  • 인증이 필요한 엔드포인트 호출Authorization: Bearer <token>
  • 프런트엔드를 스테이징으로 연결api.example.com → staging-api.example.com
  • CORS 디버깅Access-Control-Allow-Origin: *
  • 기능 플래그나 A/B 변형 강제Cookie: ab_variant=B

데이터는 브라우저 안에 머뭅니다

프로필은 로컬에 저장됩니다. 서버도, 분석도, 계정도 없으며 규칙은 브라우저가 직접 적용하므로 확장 프로그램은 자신이 바꾸는 요청을 볼 수 없습니다. 코드는 GitHub에서 확인할 수 있습니다.
