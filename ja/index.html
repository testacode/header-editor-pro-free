🎯 使い方

🔧

1. インストールして開く

Chromeに拡張機能を追加し、ツールバーのアイコンをクリックします。左側にプロファイルの丸が並ぶ、洗練されたダークテーマの画面が開きます。

⚙️

2. プロファイルを作る

「+」の丸をクリックすると、用途ごとにヘッダー設定を作れます。1つのプロファイルにリクエスト・レスポンスヘッダーをいくつでも登録できます。

🎯

3. ヘッダーを追加する

「ヘッダーを追加」ボタンから独自のHTTPヘッダーを作成できます。各ヘッダーにはチェックボックスがあり、個別に有効・無効を切り替えられます。

⚡

4. すぐに反映

ヘッダーはリアルタイムで適用されます。番号付きの丸をクリックすればプロファイルを切り替え可能。一時停止ボタンでまとめて無効にもできます。

💡 こんな場面にぴったり:

🔐 APIテスト

Authorization: Bearer token123 を追加して認証付きエンドポイントを検証

🌐 CORSのデバッグ

Access-Control-Allow-Origin: * を追加してクロスオリジンリクエストを検証

🧪 環境別のテスト

X-Environment: staging を設定して別のバックエンドに対して検証

🎭 User Agentの偽装

User-Agent を変更してモバイルとデスクトップの応答を比較

✨ 主な機能

🆓 完全無料、ずっと

サブスクリプションも、プレミアムプランも、機能制限もありません。月5〜15ドルを請求する競合とは違い、すべて完全に無料です。

🎯 プロファイル無制限

必要なだけヘッダー設定を作成できます。無料の代替ツールの多くは3プロファイルまでに制限されています。

🌐 7言語対応

English、简体中文、繁體中文、日本語、한국어、Русский、Español — ツールバーから切り替えるか、ブラウザの言語に合わせることもできます。

⚡ リアルタイム書き換え

Chromeの最新のdeclarativeNetRequest APIを使い、リクエスト・レスポンスヘッダーを即座に書き換えます。ページの再読み込みは不要です。

➕ 上書きと追記の切り替え

どのヘッダーも上書きモードと追記モードを切り替えられます。Accept、Cookie、Accept-Encodingなど複数値のヘッダーに最適です。

🗂️ ドメイン・タブグループでの絞り込み

プロファイルを特定のドメインやChromeのタブグループに限定できます。検証用ヘッダーをそのタブだけに留め、環境の取り違えを防げます。

🎨 洗練されたインターフェース

美しいダークテーマ、番号付きのプロファイルの丸、ヘッダーごとのチェックボックス、直感的な操作。

⏸️ 一時停止機能

設定を失うことなく、すべてのヘッダーを一時的に無効にできます。動作の違いをさっと比べたいときに便利です。

💾 インポートとエクスポート

ワンクリックでプロファイルをJSONファイルとしてバックアップ・共有でき、設定の読み込みも可能です。ModHeaderから書き出したプロファイルにも対応しています。

🔒 プライバシー第一

データ収集もトラッキングも一切なし。すべての設定はお使いの端末内にのみ保存されます。
