Header Editor Pro — Playground

The extension's popup is open in the first tab, with a Playground profile already set up. Change anything there, come back, and press the buttons again.

1. Request headers

What the server receives. X-Playground comes from the profile; X-Disabled shows up once you tick it. Try the pause button too. 

—

2. Response headers

What the page receives back. X-Playground-Response is added by the extension.

—

3. Redirects

The page asks for {{APP}}/desa/api/items?id=7. The profile redirects localhost:5180/desa/(.*) to {{OTHER}}/prod/$1, another origin. With CORS off the browser blocks the answer; turn the CORS toggle on in the popup and try again. 

—

Navigations are never redirected: open {{APP}}/desa/page.
