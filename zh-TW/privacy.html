隱私權政策 - Header Editor Pro - Free

你的隱私很重要： 本擴充功能以隱私優先為原則設計。我們不收集、不儲存、不傳輸任何個人資料。

資料收集

Header Editor Pro - Free 不會向外部伺服器收集、儲存或傳輸任何使用者個人資料。擴充功能完全在你的瀏覽器內運作，不與任何遠端服務通訊。

本機儲存

所有標頭設定、設定檔與偏好設定，都透過瀏覽器的儲存 API 儲存在你的裝置本機。這些資料包括：

  • 標頭修改規則與設定檔
  • 擴充功能的設定與偏好
  • 設定檔的名稱及其配置

這些資料永遠不會離開你的電腦，而且只有擴充功能本身可以存取。你隨時可以透過移除擴充功能或清除瀏覽器資料來刪除它們。

權限

本擴充功能需要下列權限才能運作：

  • declarativeNetRequest: 用於攔截並修改 HTTP 標頭
  • storage: 用於將你的設定儲存在本機
  • tabGroups: 用於讀取 Chrome 分頁群組的名稱與顏色，以便把設定檔限定在該群組
  • 存取所有網站 (<all_urls>)： 標頭規則是由瀏覽器本身透過 declarativeNetRequest 套用。擴充功能不會讀取頁面內容，也從不查看它所修改的請求。

這些權限僅用於擴充功能的運作，不會用於收集資料。

第三方服務

本擴充功能不會與任何第三方服務、分析平台或廣告聯播網整合，也不會向其傳送資料。

本政策的更新

我們可能會不定期更新本隱私權政策。任何變更都會反映在擴充功能中，以及下方的更新日期上。

聯絡方式

如果你對本隱私權政策或擴充功能的資料處理方式有任何疑問，請透過 GitHub 上的支援管道與我們聯絡。
