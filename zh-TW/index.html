🎯 使用方式

🔧

1. 安裝並開啟

把擴充功能加到 Chrome，然後點擊工具列上的圖示。你會看到一個精緻的深色介面，左側是設定檔圓圈。

⚙️

2. 建立設定檔

點擊「+」圓圈即可建立不同的標頭設定。每個設定檔都能包含任意數量的請求標頭與回應標頭。

🎯

3. 新增標頭

用「新增標頭」按鈕建立自訂的 HTTP 標頭。每個標頭都有一個核取方塊，可以個別啟用或停用。

⚡

4. 立即生效

標頭會即時套用！點擊帶編號的圓圈切換設定檔，也可以用暫停按鈕暫時停用全部規則。

💡 特別適合這些情境：

🔐 API 測試

加上 Authorization: Bearer token123 來測試需要驗證的端點

🌐 CORS 除錯

加上 Access-Control-Allow-Origin: * 來測試跨來源請求

🧪 環境測試

設定 X-Environment: staging 來對不同的後端進行測試

🎭 偽裝 User Agent

修改 User-Agent 來比較行動版與桌面版的回應

🎯 無限設定檔

需要多少標頭設定就建立多少。大多數免費替代品只允許你建立 3 個設定檔。

🌐 7 種語言

English、简体中文、繁體中文、日本語、한국어、Русский 與 Español — 可在工具列切換，也可以跟隨瀏覽器語言。

⚡ 即時修改

使用 Chrome 最新的 declarativeNetRequest API 立即修改請求標頭與回應標頭。不需要重新整理頁面！

➕ 覆寫或附加

任何標頭都可以在覆寫模式與附加模式之間切換 — 非常適合 Accept、Cookie 或 Accept-Encoding 這類多值標頭。

🗂️ 網域與分頁群組篩選

把設定檔限定在特定網域，或某個 Chrome 分頁群組 — 讓沙箱標頭只作用於對應分頁，從此不再搞混環境。

🎨 專業的介面

精美的深色主題，搭配帶編號的設定檔圓圈、每個標頭的核取方塊，以及直覺的操作方式。

⏸️ 暫停功能

暫時停用所有標頭而不會遺失設定。想快速比較測試結果時特別好用。

💾 匯入與匯出

一鍵將設定檔備份或分享為 JSON 檔案，也可以匯入設定 — 包括從 ModHeader 匯出的設定檔。
