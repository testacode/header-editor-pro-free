Política de privacidad - Header Editor Pro - Free

Tu privacidad importa: Esta extensión está diseñada con la privacidad como prioridad. No recolectamos, almacenamos ni transmitimos ningún dato personal.

Recolección de datos

Header Editor Pro - Free no recolecta, almacena ni transmite ningún dato personal del usuario a servidores externos. La extensión funciona enteramente dentro de tu navegador y no se comunica con ningún servicio remoto.

Almacenamiento local

Todas las configuraciones de headers, perfiles y preferencias se guardan localmente en tu dispositivo mediante la API de almacenamiento del navegador. Estos datos incluyen:

  • Reglas de modificación de headers y perfiles
  • Preferencias y configuración de la extensión
  • Nombres de perfiles y sus configuraciones

Estos datos nunca salen de tu computadora y solo son accesibles por la propia extensión. Podés borrarlos en cualquier momento desinstalando la extensión o limpiando los datos del navegador.

Permisos

La extensión necesita los siguientes permisos para funcionar:

  • declarativeNetRequest: Para interceptar y modificar headers HTTP
  • storage: Para guardar tus configuraciones localmente
  • tabGroups: Para leer el nombre y el color de un grupo de pestañas de Chrome, y así poder limitar un perfil a ese grupo
  • Acceso a todos los sitios web (<all_urls>): Las reglas de headers las aplica el propio navegador a través de declarativeNetRequest. La extensión no lee el contenido de las páginas, y nunca ve las requests que modifica.

Estos permisos se usan únicamente para el funcionamiento de la extensión, no para recolectar datos.

Servicios de terceros

Esta extensión no se integra con servicios de terceros, plataformas de analytics ni redes publicitarias, ni les envía datos.

Cambios en esta política

Podemos actualizar esta política de privacidad cada tanto. Cualquier cambio se va a reflejar en la extensión y en la fecha de actualización de abajo.

Contacto

Si tenés alguna consulta sobre esta política de privacidad o sobre el manejo de datos de la extensión, escribinos por los canales de soporte en GitHub.
