🎯 Как это работает

🔧

1. Установите и откройте

Добавьте расширение в Chrome и нажмите на иконку на панели инструментов. Откроется аккуратный тёмный интерфейс с кружками профилей слева.

⚙️

2. Создайте профили

Нажмите кружок «+», чтобы создать разные наборы заголовков. В каждом профиле может быть сколько угодно заголовков запроса и ответа.

🎯

3. Добавьте заголовки

Кнопки «Добавить заголовок» создают собственные HTTP-заголовки. У каждого заголовка есть флажок, чтобы включать и выключать его по отдельности.

⚡

4. Мгновенный результат

Заголовки применяются в реальном времени! Переключайте профили нажатием на пронумерованные кружки, а кнопка паузы временно отключает все правила.

💡 Идеально подходит для таких задач:

🔐 Тестирование API

Добавьте Authorization: Bearer token123, чтобы проверить эндпоинты с авторизацией

🌐 Отладка CORS

Добавьте Access-Control-Allow-Origin: *, чтобы проверить кросс-доменные запросы

🧪 Проверка окружений

Задайте X-Environment: staging, чтобы работать с разными бэкендами

🎭 Подмена User Agent

Измените User-Agent, чтобы сравнить мобильные и десктопные ответы

✨ Ключевые возможности

🆓 100% бесплатно навсегда

Никаких подписок, премиум-тарифов и урезанных функций. Всё полностью бесплатно — в отличие от конкурентов, которые берут 5–15 долларов в месяц.

🎯 Неограниченные профили

Создавайте столько наборов заголовков, сколько нужно. Большинство бесплатных аналогов ограничивают вас тремя профилями.

🌐 7 языков

English, 简体中文, 繁體中文, 日本語, 한국어, Русский и Español — переключайте на панели инструментов или оставьте язык браузера.

⚡ Изменение в реальном времени

Меняйте заголовки запросов и ответов мгновенно с помощью новейшего API declarativeNetRequest в Chrome. Перезагружать страницу не нужно!

➕ Заменить или дополнить

Любой заголовок можно переключить между режимами замены и дополнения — удобно для заголовков с несколькими значениями: Accept, Cookie или Accept-Encoding.

🗂️ Фильтры по доменам и группам вкладок

Ограничьте профиль конкретными доменами или группой вкладок Chrome — держите тестовые заголовки в своих вкладках и больше не путайте окружения.

🎨 Профессиональный интерфейс

Красивая тёмная тема с пронумерованными кружками профилей, флажками у каждого заголовка и понятным управлением.

⏸️ Функция паузы

Временно отключите все заголовки, не теряя настроек. Удобно, чтобы быстро сравнить поведение.

💾 Импорт и экспорт

Сохраняйте резервную копию профилей или делитесь ими в виде JSON-файла одним нажатием, а также импортируйте конфигурации — включая профили, выгруженные из ModHeader.
